# 纸间 · UI / 交互 / 墨水屏体验 Review 与优化方案

版本基线：v3.2.10（commit `98ebadb` 之后）
范围：`src/main.js`、`src/ui/*`、`src/app.css`、`src/ui/reader.css`、`android/`
性质：只做评审与方案，不改代码。

---

## 0. 总体结论

视觉语言已经站住了：纸墨色系、克制的圆角与阴影、Kindle 式书架规范（2:3 封面 / 固定书名槽 / 进度线）、悬浮玻璃胶囊底栏，方向是对的，不需要推倒重来。

真正拖体验的是三处**结构性欠债**，它们不是"再加个动效"能解决的：

1. **阅读器是"整页替换"，不是"浮层"**。打开一本书会把整个 `.app-shell`（含书架 DOM）销毁重建，退出时再重建一次。结果：进场看不到书架、退场淡出到空白、书架滚动位置只能靠变量恢复、每次进出都要重新查库渲染。
2. **墨水屏只做了"配色"，没做"动态预算"**。`body.reduce-motion` 这套 CSS 从来没有被任何 JS 加上（`applyInkMode()` 只切 `ink-mode`），所以墨水屏上淡化、上浮、骨架 shimmer、毛玻璃、混合模式全部照跑。
3. **滚动模式的进度计算是每帧全章重排**。`onScroll → updateProgressUI → getReadingAnchor → capturePosition`，每一帧都对整章所有 `<p>` 做 `getClientRects()` 加字符二分查找。弱 CPU 的墨水屏设备上这是硬伤。

下面按"先修 / 再改 / 后创新"排。

## 2. UI 视觉层：还能更好的地方

### 2.1 阅读页（最该动的是"信息密度"，不是装饰）

- **页脚缺页码**。分页模式底部只有进度条和"12/30 页"，正文区右下角是空的。Kindle 的页码在正文页脚外侧，属于"读的时候不用看，想看时一定有"。建议在 `.pv-content` 外叠一层固定页脚，右下角极淡的 `12 / 30`，`--rd-ink-2` 40% 透明。
- **两套时间语义混在一个工具栏**。`rd-time` 显示的是"今日已读 12 分"，页脚显示的是"本章还剩 5 分"，两个都以"分"结尾，用户分不清。建议：工具栏那个改成进度环（今日额度占比），文案放长按提示里；页脚保留"余 X 分"。
- **顶部标题栏信息太薄**。现在只有章节名。可以在标题下加一行 11px 的"书名 · 第 12/300 章"，滚动时淡出，只留章节名。
- **正文首行缩进 2em 与段距 0.9em 同时存在**，中文排版里这两者叠加会显得段落松散。建议默认段距降到 0.6em，把"段距"滑杆的默认值改掉（不改滑杆范围）。
- **夜读主题对比度偏低**（`#a8a8ac` on `#121315` ≈ 7:1，勉强够），但 `--rd-ink-2` 的 `#5c5d61` 用于页脚几乎看不见。夜读下把次要文字提到 `#7a7b80`。

### 2.2 书架

- **封面全是渐变 + 竖排书名**。同一位作者的多本书会长得很像（哈希只取书名）。建议：同一作者用同一色相、不同明度，形成"作者色系"；或在封面右下加一个 8px 的作者首字水印。
- **进度线只有 2px**，在墨水屏上几乎不可见。墨水模式下加粗到 3px 并改用纯黑。
- **"管理"和"导入"两个文字按钮挤在标题右侧**，点按目标 34px 宽，低于 44px 推荐值。建议图标化，或收进一个 `···`。

### 2.3 全局

- **毛玻璃用得偏多**：底栏、sheet 遮罩、dialog 遮罩、toast 全都有 `backdrop-filter`。Android WebView 上每一层都是一次离屏合成，中低端机上滑列表会掉帧。建议只保留底栏一层，其余改纯色 + 轻微透明。
- **圆角体系有 5 档**（10/14/20/28 + 100px 胶囊），实际用起来 14 和 20 混用。建议收敛成 3 档：12（小件）/ 18（卡片）/ 28（弹层、胶囊）。

## 3. 交互动画：可以创新的点（按投入分三档）

### 3.1 低成本、观感提升明显

1. **"书被打开"的进场**（替代现在的整屏淡入）
   从书架封面的 `getBoundingClientRect()` 做 FLIP：封面先放大到接近全屏、圆角收拢，再交叉淡入正文。300–360ms，`--ease-out`。这是"点了一本书"最自然的因果反馈，成本约 60 行。
2. **翻页跟手预览（不重排）**
   现在分页靠原生横向滚动，拖动时整屏文字在动 —— 墨水屏最怕这个。改成：拖动时只让当前页整体位移（`translateX`，最多 24px）+ 右侧一条 1px 阴影，松手超过阈值再一次性换页并淡化。视觉上"有跟手感"，实际上只有一次合成层移动。
3. **菜单栏"让位"而不是"盖住"**
   现在顶/底栏是 `translateY` 滑出，压在文字上。改成滑入的同时正文 `padding` 过渡到让出高度（或整体 `translateY` 半个栏高），读的时候不会有字被切掉一截的错觉。
4. **主题切换的圆形扩散**
   从点击的色点位置 `clip-path: circle()` 扩散到全屏（View Transitions API 不支持时降级为交叉淡化）。这是唯一值得保留的"花哨"动效，因为它解释了"颜色从哪来"。
5. **书签图标状态联动**
   当前页已有书签时，顶栏书签填充为实心；点击取消。现在图标永远是空心，用户不知道存没存上。

### 3.2 中等投入、解决真实痛点

6. **进度条可拖拽**
   现在进度条是纯展示。改成可拖：按住出现"第 128 章 · 斗破苍穹 第128章"气泡，松手跳转。长书用户靠这个，比翻目录快得多。
7. **目录加"上次阅读"分隔线**
   目录现在只有当前章高亮。加一条"上次读到这里"的细线 + 当前章自动居中（已有 `scrollIntoView`，但没有视觉标记）。另外加"已读/未读"的灰度区分（`readChapters` 已有数据）。
8. **返回时的位置确认**
   从阅读器返回书架，现在只有封面"亮一下"。改成卡片轻微上浮 + 进度线补间到新值（0.6s），让"我读到哪了"这件事被看见。
9. **下滑呼出菜单（分页模式）**
   分页模式现在上下滑完全没反应（`touch-action: pan-x`）。把"下滑 = 呼出菜单 / 上滑 = 收起"接上，符合 Kindle Oasis 与多数阅读 App 的手感，也给了一个不用点屏幕中央的入口。

### 3.3 大投入、属于"下一代功能"

10. **划线 / 批注 / 导出**
    正文已有字符级 anchor（`reading-position.js`），做选区高亮的技术底座是现成的。这是阅读 App 从"能看"到"值得用"的分水岭，但要动数据层（新表 + 同步格式），建议单独排期。
11. **阅读目标与连续天数**
    统计已有 `getWeekData()`，但没有"连续 X 天"的呈现。我的页可以加一条 7 点 streak 条 + 今日进度环。

### 3.4 明确不建议做的

- 仿真书页卷曲（page curl）：CPU 上算一次几十毫秒，墨水屏上就是一道残影。
- 翻页粒子 / 纸张飘落：和"静心阅读"的定位冲突。
- 书架视差滚动：墨水屏上等于自杀。

## 4. 交互逻辑：几个"用户会骂"的细节

1. **点击热区**：分页模式左 28% / 中 44% / 右 28%。平板上中间区有 500px 宽，想翻页却点到菜单是常事。建议中区固定 `min(44%, 360px)`，两侧均分。
2. **滚动模式上下 15% 是死区**（`reader.js:205` 直接 return）。点最上面或最下面什么都不发生，观感像失灵。改成同样呼出菜单。
3. **Android 返回键**：现在没有接管。用户按返回会直接退出 App（或退到桌面），而不是"关面板 → 退阅读器 → 退书架"。Capacitor 的 `App.backButton` 需要显式订阅。
4. **换源后位置丢失**：`source-switch` 传了 `getPosition()`，但换源成功后会重新进 reader，anchor 是按段落算的，两个源的段落切分不一样，大概率跳不准。建议换源后提示"已跳到第 N 章开头"，而不是假装精确。
5. **删除确认按钮顺序**：现在"删除"在上、"取消"在下。改成危险操作在下方独立一行，符合 iOS/Android 习惯。
6. **搜索进行中无法取消**：`searching` 为 true 时再次搜索直接 return，没有"停止"按钮。加一个可取消的入口。

## 5. 墨水屏专项（手机 + 平板）

这是这次最值得单独做一层的东西。现在只有"墨水配色"，没有"墨水行为"。

### 5.1 设备识别

三层兜底，任何一层命中即开：

1. `matchMedia('(update: slow)')` —— 专为电子墨水设计的媒体特性，部分设备/浏览器会如实上报；
2. UA 关键字：`Onyx`、`BOOX`、`Hisense`、`iReader`、`Likebook`、`Meebook`、`tolino`、`Kobo`、`Supernote`；
3. 「我的 → 纸墨护眼模式」手动开关（已有，扩展成三档：关 / 低动态 / 墨水屏）。

### 5.2 动态预算（关键）

命中墨水屏后，整站进入"零动态"：

- 所有 `transition/animation` 归零，只保留**一次** 120ms 的不透明度切换；
- `scroll-behavior: auto`（现在 `.page` 是 smooth，程序化恢复滚动位置时会动画，墨水屏上是灾难）；
- 移除 `backdrop-filter`（已有）、`mix-blend-mode`（前光层、纸纹层）、`box-shadow`、`linear-gradient` shimmer；
- 骨架屏改成静态灰块（shimmer 在墨水屏上是持续全屏刷新）；
- 封面 `filter: grayscale(1)` 保留，但去掉 `contrast/brightness` 叠加（多次滤镜会触发额外合成）。

### 5.3 对比度：现在的"墨水色"对真机是错的

`--rd-bg: #f1f0ea`、`--rd-ink: #1e1d19`。在 LCD 上这是"纸感"，但在真墨水屏上，面板被驱动到中灰，对比度反而下降、残影更明显。

建议墨水屏下用**纯白 `#ffffff` + 纯黑 `#000000`**，让面板自己的 16 级灰阶去表现层次；标题与正文的层级改用字号/字重，不用灰度。同时去掉 `text-shadow: 0 0 0.28px currentColor`（那是给 LCD 模拟墨迹渗开的，真机上是纯浪费）。

### 5.4 残影与全刷

- 提供「每 N 页全刷一次」开关（默认 10 页），实现就是整屏白 → 黑 → 白两帧（60ms），比局部刷新干净；
- 章节切换时做一次全刷（正好和现在的 `veilGlobalRefreshIn` 合并，改成纯白闪）；
- 手动全刷：双指长按 600ms，或顶栏菜单里一项。

### 5.5 平板：单栏 → 双栏跨页

现在 `colW = min(W-52, 768)`（`reader.js:378`），10 寸平板横屏 1280px 时，中间一列 768px、两侧各 256px 空白，翻一页要横移 1280px —— 这正是"最后一页偏右"的几何根源（虽然已用 `pv-tail` 补宽修掉，但布局本身不优雅）。

建议宽屏（≥900px 且横向）改成**双页跨页**：`columnWidth = (W - 3*gutter)/2`，每翻一次移动 2 列，页脚显示 `12–13 / 30`。阅读密度、翻页距离、纸书感三者同时改善。窄屏和平板竖屏保持单栏。

### 5.6 硬件翻页键

`MainActivity` 是空的（`extends BridgeActivity {}`），`onKey` 只处理了 `PageUp/PageDown/Arrow`。问题是 **音量键被系统音频服务消费，WebView 收不到 `keydown`**，而 BOOX / 汉王默认就是把音量键映射成翻页。

需要在原生层 `dispatchKeyEvent` 拦 `KEYCODE_VOLUME_UP/DOWN`（可配置开关），通过 `bridge.triggerJavascriptEvent` 或 `evaluateJavascript` 转给 Web 层。这是墨水屏设备上"能不能用"级别的功能。

### 5.7 其他墨水屏细节

- **点击目标 ≥ 48dp**：墨水屏触控采样低，38px 的顶栏按钮偏小；
- **滑动阈值提高**：现在 56px / 1.3 倍，墨水屏拖拽抖动大，建议 72px；
- **预渲染下一章**：现在只预取数据（`preloadNext`），不预排版。可以在离屏容器里提前 `measurePaged()`，翻页时零等待；
- **目录虚拟列表**：`showToc` 一次渲染 420 行且每行带 stagger 动画（`reader.js:989-994`），墨水屏上要 1 秒以上。改成只渲染可视区 ±20 行，动画在墨水屏下关闭。

## 6. 平板专项（除双栏外）

- 阅读区左右留白按 `max(48px, 8vw)`，不要用固定 26px；
- 横屏时顶栏按钮间距放大，标题居中偏移要补偿左右按钮数量不等（现在是 1 左 2 右，标题视觉偏左）；
- 支持外接键盘：`←/→` 翻页已有，补 `Space`（下一页）、`Esc`（退阅读器）；
- 支持手写笔长按划线（依赖 3.3 的划线功能）。

## 7. 建议的落地顺序

**批次 A —— 稳定性与墨水屏底座（1 次构建，风险低）**
P0-1 阅读器浮层化 → P0-2 进度计算 → P0-3 墨水屏动态预算 → P0-4 切页动画 → P0-5/6/7/8 样式修复 → P0-9/10/11/12。

**批次 B —— 交互升级（1–2 次构建）**
书页开场 FLIP、翻页跟手预览、菜单让位、书签状态、进度条拖拽、目录标记、返回高亮补间。

**批次 C —— 墨水屏专版（单独验证）**
设备识别、纯黑白 + 全刷、双栏跨页、硬件翻页键（需重新打包 APK 并在真机验证）。

**批次 D —— 功能型（另开需求）**
划线批注、阅读 streak、导出。

## 8. 需要你拍板的四件事

1. 阅读器改成浮层后，退出动画会变成"书合上"，而不是现在的"淡出到空白"——接受吗？
