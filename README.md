# 纸间 · Zhijian Reader

一个为「静心阅读」而生的安卓本地阅读器：多书源聚合搜索、Kindle 式翻页、墨水屏观感、跨设备同步，为长时间沉浸阅读而设计。

> 纸上有千言，心间只一寸。

## ✨ 功能特性

### 阅读体验
- **双阅读模式**：上下滚动 / 真实分页翻页（多列排版 + 跟手滑动）
- **Kindle 式淡化翻页**：旧页字迹渐隐 → 新页缓缓浮现，克制而沉浸
- **五种纸张主题**：纸白 / 米黄 / 墨水 / 青禾 / 夜读
- **排版可调**：字号、行距、段距；宋体（系统）/ 文楷（内置）/ 黑体三种字体
- **墨迹微渗**：正文笔画微微加厚，模拟墨水渗入纸纤维的质感

### 纸墨护眼模式
- 参考 Kindle Paperwhite 的灰阶设计（纸白 `#F2F2F2` / 墨黑 `#0C0C0C` 的柔化版）
- **四档前光色温**：2700K 琥珀 ↔ 6500K 冷白（模拟双色温前光）
- 无玻璃材质、纯净灰阶、可选纸面微纹理

### 书源与内容
- **12 个内置书源**：聚合搜索多家小说站点（SoNovel 规则 + legado 规则双引擎）
- **🍅 番茄小说全本直连**（实验性）：本地完成签名与内容解密，支持全本阅读与离线缓存
- **本地导入**：TXT（自动识别 GBK/UTF-8、智能切章）与 EPUB（完整解析章节结构）
- **离线缓存**：整本 / 章节范围缓存，支持暂停继续与断点续传；缓存后完全离线阅读
- **目录自动更新**：书源有新章节时自动发现（安全的"尾部追加"校验）

### 数据与同步
- **跨设备同步**（基于 GitHub Gist）：阅读进度（字符级锚点）、书签、书架、阅读时长全部互通
- **"读得最远的赢"**：同步冲突采用 Kindle 的"最远阅读位置"语义，绝不倒退
- **时长两边相加**：多设备阅读时长自动汇总，防沉迷限额按合计算

### 防沉迷
- 每日阅读限额（可开启"临时延长"）
- 阅读时长统计与近 7 天趋势

## 🛠 技术栈

- **前端**：原生 JavaScript（无框架）+ Vite 构建，零运行时依赖（除少量工具库）
- **移动端**：Capacitor 7 打包 Android WebView 应用
- **数据**：IndexedDB（书库/章节/进度）+ localStorage（设置）
- **关键实现**：
  - CSS 多列布局驱动的真实分页引擎（含滚动宽度校正）
  - 字符级阅读位置锚定（跨字体/屏幕精准定位）
  - 番茄 App 协议本地化：X-Argus/X-Ladon 签名 + CM 通道 DH 解密（纯 JS 实现，同步逻辑桥接异步原生网络）

## 🚀 构建

```bash
# 安装依赖
npm install

# 开发（浏览器调试，书源请求走内置代理）
npm run dev

# 构建 Web 资源
npm run build

# 同步到 Android 工程
npx cap sync android

# 打包 APK（需要 Android SDK）
npm run release -- patch   # 版本号自增并输出 APK
```
